## 1. 결론

**질문: 결정적 분석에 비해 API 비용을 낼 만한 추가 가치가 있는가?**

- **있다. 다만 "공백을 메울 테스트의 재료"로서이고, 사례에 따라 크게 다르다.** 8개 중 2개(B1·B2)는 직접 찾아야 했을 조건을 주었고, 5개는 코드에 보이는 조건을 구체적인 입력으로 옮긴 정도이며, 1개(N3)는 가치가 없었다.
- **설명은 대체로 맞았고, 약점은 테스트 제안의 실행 가능성이다** (설명 31/32, 실행 가능성 22/32).
- **가장 큰 약점은 실행 맥락을 모른다는 것이다.** 16회 중 4회(N3·B1)가 전체가 skip되는 파일에 테스트를 넣으라고 했고, skip을 언급한 응답은 없었다. 입력에 skip 정보가 없기 때문이다.
- **결함을 찾는 도구는 아니다.** 후속 수정 사례 6회 중 결함을 짚은 응답은 없었다 (F1 실행 2가 "확인이 필요"라고만 함). 프롬프트가 옳고 그름을 판단하지 말라고 하므로 예상된 결과다.
- **비용은 판단에 부담이 되지 않는다**: 공백 하나에 약 $0.015, 9초.

추천: **단일 에이전트를 선택 기능으로 유지**하고, 다음 실험은 프롬프트나 구조가 아니라 **입력에 skip 목록과 기존 테스트 정보를 넣는 것** 하나로 한다. Multi-Agent·RAG로 갈 근거는 없다.

## 4. Gap Closure

프로토콜 순서 F3 → N2 → F1 → B2, 실행 1의 제안. 건너뛴 사례 없음. 대상 커밋의 임시 스냅샷에서만 실행.

| 사례 | 실행 가능 | 공백 줄 실행 | 동작 검증 (줄을 바꾸면 실패) | 제안에서 바꾼 부분 |
|---|---|---|---|---|
| F3 | ✓ | 1/1 | ✓ | 없음 |
| N2 | ✓ | 8/8 | ✓ | import 1줄, 응답 항목 필수 필드 |
| F1 | ✓ | 4/4 | ✓ | `ROOT` monkeypatch |
| B2 | ✓ | 3/3 | ✓ | `use_fake_llm([])` 1줄, 예외 함수, `api.db` |

**4/4, 공백 16줄 전부 실행.** 다만 이 결과를 넓게 읽으면 안 된다.

- 고른 4개가 실행 가능성 점수가 높은 쪽에 몰려 있다 (순서는 결과 전에 정했지만 3개가 분류 A). 실행 가능성이 낮은 F2·N3·B1은 시도하지 않았다.
- 사례가 1~8줄의 작은 공백이다. 파일 전체가 공백인 사례는 뺐다.
- 테스트를 옮겨 쓴 것은 사람이 아니라 Claude이고, 동작 검증의 변형은 사례마다 직접 고른 1개다.
- F1의 테스트는 통과하고 공백도 메우지만, 나중에 결함으로 고쳐진 동작("가장 최근 폴더 자동 선택")을 **정답으로 고정한다**. 공백을 메우는 것과 결함을 찾는 것은 다르다.

### B1 가설 조사

| 조건 | `tests/test_app.py` | 공백 18줄 중 실행 |
|---|---|---|
| 데이터 없음 (스냅샷) | 5 skipped | 0 |
| 데이터 있음 | 5 passed | 16 |

- 가설 "skip이 공백의 원인"은 **대부분 맞다 (16/18)**.
- 남은 2줄(202~203, 새 대화 초기화)은 데이터가 있어도 실행되지 않는 진짜 공백이고, 두 실행 모두 이 동작을 테스트로 제안했다.
- 같은 이유로 스냅샷에서는 skip 파일에 넣은 제안이 실행되지 않는다 (N3·B1 4회. 이 부분은 실행하지 않고 코드로 판단).

## 5. 이 평가의 한계

- **절차 위반**: 프로토콜은 후속 수정 내용을 채점 뒤에 열도록 했지만, 채점자(Claude)가 코드 대조 중에 F1·F2의 수정을 먼저 봤다. F1·F2의 "결함을 짚었는가" 판단은 그 영향을 받았을 수 있다.
- 채점은 Claude 한 명의 초안이고, 응답을 쓴 쪽이 다른 모델이더라도 사용자 확인 전이다.
- 8개 × 2회라 일반 성능을 말할 수 없다. week1 없음, fixture 사례 없음, 작은 공백에 편향.
- 규칙 기준선은 함수 이름·조건 줄·테스트 목록을 정리한 단순한 형태다. 더 좋은 규칙 설명과 비교하면 추가 가치는 줄어들 수 있다.
- 비용은 토큰 추정치이고 청구액과 대조하지 않았다. 입력 토큰은 실행마다 2천~3만으로 차이가 크다.
