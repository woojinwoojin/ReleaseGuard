# Stage 2.2 확인 평가 — B (사람 검토) 상태

- 상태: `NOT_MEASURED` (2026-11-17, 사용자 결정)
- 사유: 사용자가 B 검토를 하기 전에 외부 리뷰어 A의 결과(`review_A.md`)를 봤다. 그래서 같은 5개 사례로는 블라인드 조건을 지킬 수 없다.
- `human_review_B.md`는 빈 양식으로 남긴다. 사람 분류와 검토 시간은 기록하지 않았다. 0분으로 간주하지 않는다.
- A(AI 리뷰어) 결과는 사람 검토 시간의 대용값이 아니다.
- 적용 규칙(설계 9장, Q7): Review Effort가 `NOT_MEASURED`이면 다른 조건을 모두 충족해도 결론은 **HOLD**다. 실험 전체가 실패했다는 뜻은 아니다. 사전에 고정한 GO 조건 중 하나를 검증하지 못했다는 뜻이다.
- 7단계(이후 이력 오라클 확인, 차등 테스트)는 그대로 진행한다.
- 사람 비용은 나중에 새 사례(A나 Claude 분류를 보지 않은 사례)로 따로 측정해야 한다.
