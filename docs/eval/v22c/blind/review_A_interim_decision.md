## 블라인드 A 5건

- ACTIONABLE **후보**: R-2, W-1 — 각 1건, 명세 확인 및 차등 테스트 필요.
- LOW_VALUE: R-1, P-1, P-2 — 각 변경은 출력 형식/길이의 차이를 일으키지만 패킷에 계약 없음.
- confirmed ACTIONABLE: **아직 0건**, 이 숫자는 실패 수가 아니라 미실시 검증 상태.
- 별도 재현: W-1에서 부모 매칭 1행이면 mutant `iloc[1]`이 `IndexError`가 됨 (pandas 소규모 실험). R-2는 텍스트 길이가 cap과 같은 경우 경계 플래그가 불일치함 (코드 수준 확인).

## 사전 GO/HOLD 조건

- R·W 각 confirmed ACTIONABLE 1건 이상: **미검증** (현재 각 1건 후보).
- 서로 다른 커밋 2개 이상: **가능성** (R-2 `6fb437c`, W-1 `5b31f70`, 미확정).
- 기존 coverage보다 추가 정보 1건: **후보 있음** (패킷은 executed line만 선정, 추가 테스트 결과 없음).
- 실행 비용 중앙값 기준: **보고된 범위에서는 충족 가능**, 원본 자료로 정확한 중앙값 추후 확인.
- 사람 검토 시간 중앙값 5분 이하: **NOT_MEASURED**, GO 불가.

따라서 현재 정식 Stage 2.2 통합에 대한 최종 승인은 보류. 기술적 성공 가능성을 보였다는 사실과 사전 비용 GO 기준 미충족을 분리해야 함.

## 실제 다음 단계

1. A 리뷰 결과를 독립 파일로 고정하고 기존 Claude 분류와 비교한다. 현재 Claude 분류 원본은 제공되지 않았으므로 비교 결과는 비워 둔다.
2. 사람 검토를 생략하는 선택을 `NOT_MEASURED`로 고정한다. AI 검토를 인간 기록으로 위장하지 않는다.
3. 남은 5개 SURVIVED도 전수 검토하고 R-2/W-1 등을 대상으로 사전 시점 명세와 실제 차등 테스트를 확인한다.
4. 정식 의사결정은 사전 기준에 따라 HOLD로 유지하거나, 나중에 실제 사람 비용 자료가 확보된 별도의 확인 평가에서 재심한다.
